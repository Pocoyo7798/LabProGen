# Protocols

One laboratory procedure per file (`.yaml`, `.yml` or `.json`), as exported by
the LabProGen GUI: a `LabProcedure` with `protocol_name` and
`laboratory_actions`, or an export with a list of procedures under
`activities`. A comment block at the top of the file is shown on the schema
map as the protocol's source text.

Submit a protocol with the "Submit a protocol" button on the schema map, or
upload it here; it then appears on the map's Protocols tab.
